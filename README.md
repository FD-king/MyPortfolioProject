# 🚀 Modern Personal Portfolio

A lightning-fast, highly responsive single-page personal portfolio built with **Next.js**, **TypeScript**, and **Tailwind CSS**. Designed meticulously following custom Figma design tokens, featuring dark-mode glassmorphism, smooth animations, and interactive components.

## ✨ Features

- **🎨 Pixel-Perfect Figma Implementation**: Adheres precisely to custom design tokens, primary color palettes (`#100425` dark backgrounds, `#5DFFFF` cyan accents), and custom asset layouts.
- **⚡ Responsive Single-Page Layout**: Seamless navigation across Hero, About, Projects, Contact, and Footer sections.
- **🖼️ Complex Layered Project Cards**: Custom `z-index` layering and shadow effects aligning project screenshots with description containers.
- **✨ Animated Glassmorphic Feedback Modal**: Sleek top-sliding slide-down entrance animation upon form submission.
- **📨 Fully Integrated Contact System**: Powered by Web3Forms for direct delivery to your primary Gmail inbox with instant reply-to capability.
- **🌙 Typography & Styling**: Styled with Google Fonts (`Josefin_Sans`) and smooth scrolling behavior.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: `react-icons`
- **Form Backend**: [Web3Forms](https://web3forms.com/)
